# Design and Develop a Gesture-Based Counter

## Project Overview
This is a low-budget college minor project in Hardware, IoT, and Smart Devices.

## Objective
To develop a smart counter that detects hand movements using a gesture sensor and ESP32.

## Components
- ESP32 microcontroller
- APDS-9960 gesture sensor
- USB cable and jumper wires
- Optional OLED display

## Working Principle
The sensor detects supported hand movements. The ESP32 processes the gesture and updates the counter. Wi-Fi can be used to send counter data to an IoT dashboard.

## Project Status
Planning and component selection.

## Future Scope
- Display the count on an OLED
- Monitor the count using an IoT dashboard
- Improve gesture detection and reliability
